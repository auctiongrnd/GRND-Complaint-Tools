Install and update guide

Downloads are manual: choose a ZIP above, extract it, then load the folder in your browser. The portal never installs an update automatically.

Install or update in Chrome
  1. Download and extract the extension ZIP.
  2. Open chrome://extensions and turn on Developer mode.
  3. For a first install, choose Load unpacked and select the extracted folder containing manifest.json.
  4. For an update, replace the old folder with the new files, then select Reload on the extension card.
Install or update in Microsoft Edge
  1. Download and extract the extension ZIP.
  2. Open edge://extensions and turn on Developer mode.
  3. For a first install, choose Load unpacked and select the extracted folder containing manifest.json.
  4. For an update, replace the old folder with the new files, then select Reload on the extension card.

Quick answers

How do I share an idea or report a problem?

Create an account or sign in, open the Feedback section, and send a short description. You can follow the status under My submissions.

Who can publish announcements and releases?

Only approved staff can publish. User accounts cannot edit extension releases or announcements.
